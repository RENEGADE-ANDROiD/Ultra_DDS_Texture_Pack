# Ultra .DDS Texture Pack

This is the Ultra texture and materials pack converted to .dds format for performance.  
Most heavy textures needed downscaled for best performance as well, minus the detailed crisp textures and materials that mattered most.

Screenshots courtesy of Doc.  Tasteful
 CRT scanlines are not included.

https://www.moddb.com/mods/dds-texturespbr-plus
